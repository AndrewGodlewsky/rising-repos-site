# Research

What was read or tried to settle a question before the site changed. Each note
says the question it answers and gives the source of each claim. The folder is
a record, kept so that a decision's reasons can be read again: nothing here is
built, deployed, or run by a check or a workflow.

Some notes keep the code they ran beside them, in a folder of the same name:
the scripts that measured a search and a reading window, the four Workers of
the language trial, and the prototype of the agent copy. Each answered one
question once. It is laid out as the lint and the format ask, and is otherwise
as it was run, so it may no longer run against the site or the data as they
are now.

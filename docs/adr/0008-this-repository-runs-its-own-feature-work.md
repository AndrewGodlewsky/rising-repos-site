# This repository runs its own feature work, and holds its own rules

An idea for the site is an issue in this repository, and it is planned, built,
reviewed, and shipped here, by this repository's own workflow. The rules a
change is held to, the decisions already made, and the words for the domain
are kept here too, in `STANDARDS.md`, `docs/adr/`, and `GLOSSARY.md`. The
owner decided this on 22 November 2026, so that an agent adding a feature has
the site's do's and don'ts to hand, and turns to RisingRepos only for what
RisingRepos owns, which is chiefly the data.

## Status

Accepted on 22 November 2026, by the owner. It departs from RisingRepos's
decision record 0004, which has the site's work planned in RisingRepos's
tracker. That record is RisingRepos's to change.

**Not yet in force.** The workflow is still being planned
(`docs/workflow-plan.md`). Until its documents replace that plan, `AGENTS.md`
says how work is delivered here.

## Consequences

- Work that needs data the site does not receive is asked of RisingRepos, in
  an issue there, and done by its own agents. The site's work waits for it.
- A decision about the site is recorded here, in a record like this one, and
  a rule about the site in `STANDARDS.md`.
- Nothing here quotes the private repository
  ([0007](0007-the-repository-is-public-and-holds-nothing-private.md)).
